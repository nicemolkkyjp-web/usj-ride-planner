# usj-ride-planner

USJ(ユニバーサル・スタジオ・ジャパン)に行く日、乗りたいアトラクションと入園予定時刻を入力すると、時間帯別の混雑予測をもとに「どの順番でどのくらい並んで回るか」を提案するアプリです。

ビルド不要の静的サイト(HTML / CSS / Vanilla JS のみ)なので、ブラウザで `index.html` を開くか、GitHub Pages でそのまま公開して使えます。

## 使い方

1. `index.html` をブラウザで開く(または GitHub Pages で公開したURLにアクセスする)。
2. 来園日・混雑区分(平日/土日/繁忙期など)・入園予定時刻・退園予定時刻・体感混雑度を入力する。
3. 乗りたいアトラクションにチェックを入れて「プランを作成」を押す。
4. 提案された周る順番・予想待ち時間・時間帯別の混雑予測グラフが表示される。
5. 実際に来園した後、体験した待ち時間を「実際の待ち時間を記録」フォームに入力しておくと、そのアトラクションの次回以降の予測に反映される(ブラウザのlocalStorageに保存され、次回同じ端末で開いたときに使われます)。

## 予測の仕組み

- アトラクションごとに「人気度ティア(1〜5)」と、時間帯(9時〜21時)ごとの混雑倍率カーブを `data.js` にあらかじめ定義しています。
- フライング・ダイナソーのように「午前〜昼は混みやすく、夕方以降は空きやすい」といった個別の傾向は、専用のカーブ(`tier5_evening_dip`)として反映しています。
- 混雑区分(平日/土日/祝日/繁忙期/イベント期)と体感混雑度(前日・前週の様子など)で全体の倍率を調整します。
- 実際に記録した待ち時間があれば、予測値との比率をもとに±40%の範囲で補正します。
- 周る順番は、現在地からの移動時間とその時点での予想待ち時間の合計が最も小さいアトラクションを優先する貪欲法で決定します。最後に残った1つについては、閉園までの間でより空いていそうな時間帯があれば、あえてそこまで時間をずらす提案をします。

## 注意事項

このアプリが表示する待ち時間は、公開情報や一般的な傾向をもとにした**目安の予測**であり、公式の実測データではありません。実際の混雑状況は天候・当日のイベント・アトラクションの稼働状況などにより変動します。参考情報としてご利用ください。
